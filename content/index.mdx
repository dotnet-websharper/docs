## Get started

Go from zero to a running WebSharper project in three steps.

<Steps>

<Step>

Install the WebSharper project templates:

```bash
dotnet new install WebSharper.Templates
```

</Step>

<Step>

Create a project — pick F# or C#:

<Tabs items={['F#', 'C#']}>

<Tab value="F#">

```bash
dotnet new websharper-web -lang F# -n MyApp
```

</Tab>

<Tab value="C#">

```bash
dotnet new websharper-web -lang C# -n MyApp
```

</Tab>

</Tabs>

</Step>

<Step>

Run it and open the printed URL:

```bash
cd MyApp && dotnet run
```

</Step>

</Steps>

Follow the [Getting started guide](/core/getting-started) for the full walkthrough.
